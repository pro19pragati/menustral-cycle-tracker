# SAKHI – Menstrual Cycle & Fertility Tracker

**SAKHI** is a menstrual health and conception-planning web application designed around user needs identified through a survey. It provides cycle tracking, fertility estimates, and educational support through two dedicated modes: General Cycle Tracking and Trying to Conceive (TTC).

### Key Features
- **Dual Modes:** General cycle tracking and conception planning.
- **Cycle Tracking:** Log periods, symptoms, and mood.
- **Fertility Tracking:** Record cervical fluid observations and basal body temperature (BBT).
- **Cycle Predictions:** Period forecasts and estimated fertile windows.
- **TTC Guidance:** Conception-planning information and educational resources.
- **Health Chatbot:** KMP algorithm-based chatbot with Learn and Support modes.
- **Algorithm Demonstrations:** Interactive algorithm demonstrations.
- **Privacy-Conscious Storage:** Stores user records locally in the browser.

### Tech Stack
- HTML, CSS, JavaScript
- Browser Local Storage
- KMP (Knuth-Morris-Pratt) Algorithm

### Project Highlight
Combines survey-informed design, menstrual cycle tracking, fertility planning, and educational support in one application.

### Disclaimer
SAKHI is an educational planning tool, not a medical device. Predictions are estimates and should not replace professional medical advice.
